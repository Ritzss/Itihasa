# Itihas

> Read • Listen • Learn

Itihas is a React Native application dedicated to preserving, organizing, and making accessible the timeless wisdom, stories, and scriptures of Sanatan Dharma through a modern mobile experience.

The application allows users to explore the history, teachings, characters, and events of the Four Yugas:

- Satya Yuga
- Treta Yuga
- Dvapara Yuga
- Kali Yuga

Users can read scriptures, listen to audiobooks, track progress, bookmark chapters, and explore interactive timelines and character relationships.

---

## ✨ Features

### 📖 Digital Library
- Read scriptures and epics chapter by chapter
- Clean and distraction-free reading experience
- Adjustable font size
- Light and dark mode

### 🎧 Audiobooks
- Stream chapter audio
- Background playback
- Playback speed controls
- Continue listening from last position

### 🔖 Progress Tracking
- Track reading progress
- Continue from where you left off
- Reading history
- Completed chapters and books

### 📝 Notes & Bookmarks
- Bookmark chapters
- Save favorite passages
- Create personal notes

### 🕉️ Yuga Timeline
Explore events across:

- Satya Yuga
- Treta Yuga
- Dvapara Yuga
- Kali Yuga

View important events, characters, and scriptures associated with each era.

### 👤 Character Encyclopedia
Learn about major figures including:

- Rama
- Sita
- Hanuman
- Krishna
- Arjuna
- Bhishma
- Karna
- Prahlada
- Dhruva
- Ravana

and many more.

### 🔍 Smart Search
Search by:
- Character
- Scripture
- Chapter
- Event
- Yuga

### 🌐 Multi-language Support
Planned support for:
- English
- Hindi
- Sanskrit
- Other Indian languages

### 📥 Offline Reading
Download content for offline access.
